# Workflow E: Create new Foundry formation from intent

This workflow assembles a new Foundry formation from intent. Alloy maps the situation to capabilities, threats, strategies, and evidence, then emits a [[formation-brief|formation brief]] that Foundry executes using existing blocks where possible.

1. User defines a new engineering situation.
2. Alloy identifies relevant capabilities, threats, strategies, and evidence.
3. Alloy selects candidate Foundry blocks and agent roles.
4. Alloy emits a formation brief.
5. Foundry executes using existing blocks where possible.
6. If Foundry lacks a needed block, Alloy records a specification gap.

See also the other [[workflows]] and the implementation journey [[workflow-implement-epilogue-interaction]].
